PROBLEM 1: CSS/Script-Code im Druck
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SYMPTOM:
  ❌ Formatierter CSS-Code wurde mitgedruckt
  ❌ Beispiel: "body { background: red; color: white; }"

URSACHE:
  • Regex-Pattern `.` erfasste nicht Zeilenumbrüche
  • Pattern.DOTALL flag fehlte

LÖSUNG:
  ✅ Pattern.DOTALL hinzugefügt
  ✅ Pattern.compile() mit CASE_INSENSITIVE
  ✅ Lazy Quantifier (.*?) für Blöcke

RESULT:
  ✅ CSS-Blöcke (<style>) vollständig entfernt
  ✅ JavaScript-Blöcke (<script>) vollständig entfernt
  ✅ Inline style='' Attribute entfernt
  ✅ Event-Handler (onclick, onload, etc.) entfernt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PROBLEM 2: Layout-Abstände zu groß
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SYMPTOM:
  ❌ Zu große Abstände zwischen Zeilen
  ❌ Nicht aller Text passte auf eine Seite
  ❌ Professionelles Layout nicht erreicht

URSACHE:
  • Jede Zeile: y += lineHeight + 5 (verschleudert Platz)
  • Mehrfache Zeilenumbrüche → große Lücken
  • Leere Zeilen übersprungen, aber Abstand trotzdem gezählt

LÖSUNG:
  ✅ Abstände reduziert: lineHeight + 5 → lineHeight
  ✅ Absatzabstände: lineHeight * 0.5 statt full lineHeight
  ✅ Mehrfache Zeilenumbrüche: 3+ auf max 2 reduziert
  ✅ Intelligentes Handling von leeren Zeilen
  ✅ Oberer Rand: 20 → 15 Pixel kleiner

RESULT:
  ✅ Professionelle Abstände
  ✅ Mehr Inhalt pro Seite
  ✅ Dateigröße reduziert (6.5K → 5.9K)
  ✅ Optimales Layout für Briefe

1. HTML-Template wird im WebView-Editor erstellt
2. Beim Drucken wird HtmlDrucker verwendet:

   HtmlDrucker drucker = new HtmlDrucker(finalHtml);
   job.setPrintable(drucker, pf);
   job.print(attributes);

3. HtmlDrucker durchläuft dann:
   ✅ stripHtmlTags() - CSS wird entfernt
   ✅ renderHtmlAsText() - Optimiertes Layout
   ✅ print() - Auf Drucker ausgegeben
